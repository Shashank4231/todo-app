# Todo List App

A simple Todo List application built using HTML, CSS, and JavaScript. This project allows users to add, complete, and delete tasks.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Clean and responsive user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/todo-list-app.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
